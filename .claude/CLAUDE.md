# CLAUDE.md

## ツールの使い分け

### コードの書き換えは Edit tool か IDE のリファクタリングで行う

`sed` / `perl -pi` / Python スクリプトでの一括置換をしない。Edit の呼び出し回数を減らせても、正規表現による書き換えは壊れやすく、何をしたかが差分に残らないため確認できない。

- 単純な編集 … Edit tool（同じ文字列が複数あるなら `replace_all`）
- シンボルの改名や参照の追随 … 後述の PhpStorm MCP
- 一時的に一部の変更だけを取り消した中間状態を作る場合も、Edit で明示的に消す

### コードの分析やリファクタリング時には PhpStorm MCP を利用する

テキスト置換や grep で済ませず、コードの構造を理解している PhpStorm の MCP ツールを使う。ツールのスキーマは ToolSearch で `select:mcp__phpstorm__<名前>` として読み込む。

PHP に限らず TypeScript でも動作する（`rename_refactoring` / `analyze_calls` / `search_text` で確認済み）。

#### リファクタリング

- **`rename_refactoring`** … シンボル（クラス・メソッド・プロパティ・変数）の改名。参照を全て追随させるので、改名は原則これを使う
  - 引数: `pathInProject`（シンボルが**宣言されている**ファイル）/ `symbolName` / `newName` / `projectPath`
  - **クラス名を変えてもファイル名は追随しない**。改名後に `git mv` でファイル名を合わせ、オートロードが壊れていないことを確認する
  - 実行後は該当ファイルがディスク上で書き換わるため、Edit / Write の前に読み直す
- **`reformat_file`** … IDE の整形ルールを適用する。ただし本リポジトリの整形は `task bq`（php-cs-fixer）が正なので、最終的にはそちらで確認する

#### 調査・分析

- **`search_symbol`** … 識別子の断片からクラス・メソッド・プロパティを探す。`paths` で glob 絞り込みができる
- **`analyze_calls`** … 呼び出し階層。`INCOMING_CALLS` で「誰が呼んでいるか」、`OUTGOING_CALLS` で「何を呼んでいるか」。影響範囲の調査は grep より先にこれを使う。FQN が曖昧なときは `search_symbol` で特定してから渡す
- **`get_symbol_info`** … ファイル内の位置（1 始まりの行・列）にあるシンボルの宣言・型・ドキュメントを引く
- **`search_structural`** … 構造検索（SSR）。`$a$->$b$()` のようなパターンでコード構造として検索する。正規表現では拾いにくい書き方の揺れを探すときに使う
- **`get_file_problems`** … IDE のインスペクション結果。`task bq` を回す前の当たりを付けるのに使う

#### 使う場面の目安

| やりたいこと | 使うもの |
|:--|:--|
| 改名 | `rename_refactoring` |
| 影響範囲・呼び出し元の把握 | `analyze_calls` |
| どこで定義されているか | `search_symbol` / `get_symbol_info` |
| 書き方の揺れを構造で探す | `search_structural` |
| 単純な文字列・ファイル名の検索 | Grep / Glob（MCP を使う必要はない） |

## コミット

### 作業単位で分割する

1つのタスクの成果物をまとめて1コミットにしない。「〜を切り出す」「〜を追加する」「〜できるようにする」といった単位に分け、それぞれが独立して読める粒度にする。

## 実装

### コードから読み取れることをコメントに書かない

コメントに残すのは、コードを読んでも分からないことだけにする。

- 残す: 設計上の意図、外部仕様の制約（RFC など）、アルゴリズム名、コードから読み取れない前提
- 消す: 関数名・型名・スタイル定義の言い換え、実装したときの修正の経緯

特に、対話の中で「表示が崩れているので直して」といった指摘を受けて書いたコードに、その経緯を説明するコメントを付けない。後から読む人に必要なのは指摘の履歴ではなく、そのコードが今どういう判断で書かれているかだけ。
